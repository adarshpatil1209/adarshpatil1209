### 🛰️ AgroSense-AI — Satellite Intelligence for Precision Irrigation

\<kbd>HACKATHON PROJECT\</kbd>

Phenology-Aware Satellite Intelligence for Precision Irrigation.

An agricultural intelligence project exploring satellite-derived indicators to support irrigation decisions.

- Google Earth Engine-based analysis.
- Machine learning for irrigation intelligence.
- Team leadership and project development.
